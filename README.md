# CYBER // OPERATIONS CENTER

A full-screen simulated cybersecurity monitoring wallboard built for demonstration and presentation use.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

GitHub Actions automatically deploys the `dist` output to GitHub Pages whenever the `main` branch changes.

All telemetry, indicators, identities, systems, and incidents displayed by this project are fictional and intended solely for demonstration.
